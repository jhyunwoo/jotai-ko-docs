이 가이드는 Jotai의 핵심 구현을 이해하려는 사람들에게 유용합니다. 완전한 예를 제시하려는 것은 아닙니다.
핵심 구현이 아니라 단순화된 버전입니다. 카토 다이시([@dai_shi](https://twitter.com/dai_shi))의 트윗 모음에서 영감을 받았습니다.

### 첫 번째 버전

쉬운 예부터 시작해 보겠습니다. Atom은 구성 객체를 반환하는 함수일 뿐입니다. 우리는 WeakMap을 사용하여 원자를 상태와 매핑합니다.
WeakMap은 키를 메모리에 보관하지 않으므로 원자가 가비지 수집되면 해당 상태도 가비지 수집됩니다. 이는 메모리 누수를 방지하는 데 도움이 됩니다.

```js
import { useState, useEffect } from 'react'

// Atom 함수는 초기 값을 포함하는 구성 객체를 반환합니다.
export const atom = (initialValue) => ({ init: initialValue })

// 우리는 원자의 상태를 추적해야 합니다.
// 메모리 누수를 피하기 위해 Weakmap을 사용하고 있습니다.
const atomStateMap = new WeakMap()
const getAtomState = (atom) => {
  let atomState = atomStateMap.get(atom)
  if (!atomState) {
    atomState = { value: atom.init, listeners: new Set() }
    atomStateMap.set(atom, atomState)
  }
  return atomState
}

// useAtom 후크는 현재 값의 튜플을 반환합니다.
// 원자의 값을 업데이트하는 함수
export const useAtom = (atom) => {
  const atomState = getAtomState(atom)
  const [value, setValue] = useState(atomState.value)
  useEffect(() => {
    const callback = () => setValue(atomState.value)

    // 동일한 원자가 여러 구성 요소에서 사용될 수 있으므로 다음을 수행해야 합니다.
    // 구성 요소가 마운트 해제될 때까지 원자의 상태 변경을 계속 수신합니다.
    atomState.listeners.add(callback)
    callback()
    return () => atomState.listeners.delete(callback)
  }, [atomState])

  const setAtom = (nextValue) => {
    atomState.value = nextValue

    // 구독 중인 모든 구성 요소에 원자의 상태가 변경되었음을 알립니다.
    atomState.listeners.forEach((l) => l())
  }

  return [value, setAtom]
}
```

### 두 번째 버전

잠깐만요! 우리는 더 잘할 수 있습니다. Jotai에서는 파생 원자를 생성할 수 있습니다. 파생 원자는 다른 원자에 의존하는 원자입니다.

```js
const priceAtom = atom(10)
const readOnlyAtom = atom((get) => get(priceAtom) * 2)
const writeOnlyAtom = atom(
  null, // 첫 번째 인수에 `null`를 전달하는 것이 관례입니다.
  (get, set, args) => {
    set(priceAtom, get(priceAtom) - args)
  },
)
const readWriteAtom = atom(
  (get) => get(priceAtom) * 2,
  (get, set, newPrice) => {
    set(priceAtom, newPrice / 2)
    // 동시에 원하는 만큼 많은 원자를 설정할 수 있습니다.
  },
)
```

모든 종속 항목을 추적하려면 원자 상태에 속성을 하나 더 추가해야 합니다. 원자 X가 원자 Y에 의존한다고 가정해 보겠습니다.
따라서 원자 Y를 업데이트하면 원자 X도 업데이트됩니다. 이를 종속성 추적이라고 합니다.

```js
const atomState = {
  value: atom.init,
  listeners: new Set(),
  dependents: new Set(),
}
```

이제 종속 원자의 상태 업데이트를 처리할 수 있는 원자를 읽고 쓰기 위한 함수를 만들어야 합니다.

```js
import { useState, useEffect } from 'react'

export const atom = (read, write) => {
  if (typeof read === 'function') {
    return { read, write }
  }
  const config = {
    init: read,

    // 읽기 기능을 사용하면 원자 값을 읽는 것입니다.
    // 반응형이며 읽기 종속성이 추적됩니다.
    read: (get) => get(config),

    // 쓰기 함수에 들어가는 것도 원자 값을 읽는 것이지만 추적되지는 않습니다.
    // 쓰기 기능에 설정된 것은 원자 값을 쓰는 것이고
    // 대상 원자의 쓰기 기능을 호출합니다.
    write:
      write ||
      ((get, set, arg) => {
        if (typeof arg === 'function') {
          set(config, arg(get(config)))
        } else {
          set(config, arg)
        }
      }),
  }
  return config
}

// 위와 동일하지만 상태에는 종속 항목이라는 추가 속성이 하나 있습니다.
const atomStateMap = new WeakMap()
const getAtomState = (atom) => {
  let atomState = atomStateMap.get(atom)
  if (!atomState) {
    atomState = {
      value: atom.init,
      listeners: new Set(),
      dependents: new Set(),
    }
    atomStateMap.set(atom, atomState)
  }
  return atomState
}

// 원자가 원시적이면 그 값을 반환합니다.
// 원자가 파생되면 상위 원자의 값을 읽습니다.
// 현재 원자를 부모의 종속 집합에 (재귀적으로) 추가합니다.
const readAtom = (atom) => {
  const atomState = getAtomState(atom)
  const get = (a) => {
    if (a === atom) {
      return atomState.value
    }
    const aState = getAtomState(a)
    aState.dependents.add(atom) // XXX 추가만
    return readAtom(a) // XXX 캐싱 없음
  }
  const value = atom.read(get)
  atomState.value = value
  return value
}

// atomState가 수정되면 모든 종속 Atom에 (재귀적으로) 알려야 합니다.
// 이제 이 Atom에 종속된 모든 구성 요소에 대해 콜백을 실행합니다.
const notify = (atom) => {
  const atomState = getAtomState(atom)
  atomState.dependents.forEach((d) => {
    if (d !== atom) notify(d)
  })
  atomState.listeners.forEach((l) => l())
}

// writeAtom은 필요한 매개변수를 사용하여atom.write를 호출하고 알림 기능을 트리거합니다.
const writeAtom = (atom, value) => {
  const atomState = getAtomState(atom)

  // 'a'는atomStateMap의 일부 원자입니다.
  const get = (a) => {
    const aState = getAtomState(a)
    return aState.value
  }

  // 'a'가 원자와 동일하면 값을 업데이트하고 해당 원자에 알리고 반환합니다.
  // 그렇지 않으면 'a'에 대해 writeAtom을 호출합니다(재귀적으로).
  const set = (a, v) => {
    if (a === atom) {
      atomState.value = v
      notify(atom)
      return
    }
    writeAtom(a, v)
  }

  atom.write(get, set, value)
}

export const useAtom = (atom) => {
  const [value, setValue] = useState()
  useEffect(() => {
    const callback = () => setValue(readAtom(atom))
    const atomState = getAtomState(atom)
    atomState.listeners.add(callback)
    callback()
    return () => atomState.listeners.delete(callback)
  }, [atom])
  const setAtom = (nextValue) => {
    writeAtom(atom, nextValue)
  }
  return [value, setAtom]
}
```
