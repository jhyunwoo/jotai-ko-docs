Jotai는 React 개발의 기본으로 돌아가면서도 모든 것을 단순하게 유지하도록 도와주는 라이브러리입니다.

### 처음부터

Jotai를 우리가 이전에 알던 것들과 비교해 보기 전에, 아주 단순한 것부터 바로 살펴보겠습니다.

React의 세계는 우리 세계와 꽤 비슷합니다. 작은 개체들이 모여 있는 큰 집합이고, 우리는 그것을 컴포넌트라고 부르며 각자 자신의 상태를 가진다는 것을 알고 있습니다. 이 컴포넌트들이 서로 상호작용하도록 구조를 잡으면 앱이 만들어집니다.

Jotai의 세계에도 작은 개체인 atom이 있고, 이들 역시 각자의 상태를 가집니다. atom을 조합하면 앱의 상태가 만들어집니다.

Jotai는 무엇이든 atom으로 다룰 수 있다고 생각합니다. 그래서 이렇게 말할 수도 있습니다: `어? 객체와 배열이 필요하고, 그걸 필터링한 다음 정렬해야 하는데.`
그런데 바로 그 점이 Jotai의 매력입니다. Jotai는 더 단순한 atom들로부터 파생된 단순한 atom들을 자연스럽게 만들 수 있게 해줍니다.

예를 들어 온라인 친구와 오프라인 친구라는 두 개의 탭이 있는 페이지가 있다고 해봅시다.
그러면 하나의 더 단순한 공통 소스로부터 간단히 파생된 두 개의 atom을 만들 수 있습니다.

```js
const dumbAtom = atom([{ name: 'Friend 1', online: false }])
const onlineAtom = atom((get) => get(dumbAtom).filter((item) => item.online))
const offlineAtom = atom((get) => get(dumbAtom).filter((item) => !item.online))
```

이런 식으로 복잡성은 얼마든지 확장해 나갈 수 있습니다.

Jotai의 또 다른 놀라운 기능은 비동기 atom을 사용할 때 suspend할 수 있는 기능이 기본으로 들어 있다는 점입니다. 이것은 비교적 새로운 기능이라 더 많은 실험이 필요하지만, React 앱을 만드는 방식의 미래라고 할 만한 기능입니다. 자세한 내용은 [React 문서](https://react.dev/blog/2022/03/29/react-v18#new-suspense-features)를 확인하세요.
