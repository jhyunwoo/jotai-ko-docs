## @swc-jotai/react-refresh

이 플러그인은 Jotai 원자에 대한 React 새로 고침 지원을 추가합니다. 이렇게 하면 React 새로 고침을 사용하여 개발할 때 상태가 재설정되지 않습니다.

### 사용법

다음을 사용하여 설치하세요.

```sh
npm install --save-dev @swc-jotai/react-refresh
```

`.swcrc`에 플러그인을 추가할 수 있습니다:

```json
{
  "jsc": {
    "experimental": {
      "plugins": [["@swc-jotai/react-refresh", {}]]
    }
  }
}
```

Next.js의 [실험적인 SWC 플러그인 기능](https://nextjs.org/docs/advanced-features/compiler#swc-plugins-experimental)와 함께 플러그인을 사용할 수 있습니다.

```js
module.exports = {
  experimental: {
    swcPlugins: [['@swc-jotai/react-refresh', {}]],
  },
}
```

아래에서 예를 확인할 수 있습니다.

## @swc-jotai/debug-label

Jotai는 키(예: Recoil)가 아닌 개체 참조를 기반으로 합니다. 이는 원자에 대한 식별자가 없음을 의미합니다. 원자를 식별하려면 원자에 `debugLabel`를 추가하는 것이 가능하며, 이는 React 개발 도구에서 찾을 수 있습니다.

그러나 모든 원자에 `debugLabel`를 추가하는 것은 금방 번거로울 수 있습니다.

이 `SWC` 플러그인은 식별자를 기반으로 모든 원자에 `debugLabel`를 추가합니다.

플러그인은 다음 코드를 변환합니다.

```js
export const countAtom = atom(0)
```

안으로:

```js
export const countAtom = atom(0)
countAtom.debugLabel = 'countAtom'
```

파일 이름 지정에 따라 기본 내보내기도 처리됩니다.

```js
// countAtom.ts
export default atom(0)
```

다음과 같이 변환됩니다.

```js
// countAtom.ts
const countAtom = atom(0)
countAtom.debugLabel = 'countAtom'
export default countAtom
```

다음을 사용하여 설치하세요.

### 사용자 정의 원자 이름

사용자 정의 Atom에 대한 플러그인을 활성화할 수 있습니다. 아래와 같이 플러그인에 제공할 수 있습니다.

```js
module.exports = {
  experimental: {
    swcPlugins: [
      ['@swc-jotai/debug-label', { atomNames: ['customAtom'] }],
      ['@swc-jotai/react-refresh', { atomNames: ['customAtom'] }],
    ],
  },
}
```
