## jotai-babel/plugin-react-refresh

이 플러그인은 Jotai 원자에 대한 React 새로 고침 지원을 추가합니다. 이렇게 하면 React 새로 고침을 사용하여 개발할 때 상태가 재설정되지 않습니다.

### 사용법

`babel` 구성 파일 사용:

```json
{
  "plugins": ["jotai-babel/plugin-react-refresh"]
}
```

플러그인은 미리 정의된 원자 함수 이름 목록(예: 'atom', 'atomFamily', 'atomWithDefault')을 인식합니다. 사용자 정의 원자 함수 이름을 사용하는 경우 해당 이름을 명시적으로 제공하여 인식되도록 할 수 있습니다.

Babel 설정에서 구성하는 방법은 다음과 같습니다.

```json
{
  "plugins": [
    ["jotai-babel/plugin-react-refresh", { "customAtomNames": ["customAtom"] }]
  ]
}
```

아래에서 예를 확인할 수 있습니다.

## jotai-babel/plugin-debug-label

Jotai는 키(예: Recoil)가 아닌 개체 참조를 기반으로 합니다. 이는 원자에 대한 식별자가 없음을 의미합니다. 원자를 식별하려면 원자에 `debugLabel`를 추가하는 것이 가능하며, 이는 React 개발 도구에서 찾을 수 있습니다.

그러나 모든 원자에 `debugLabel`를 추가하는 것은 금방 번거로울 수 있습니다.

이 `babel` 플러그인은 식별자를 기반으로 모든 원자에 `debugLabel`를 추가합니다.

플러그인은 다음 코드를 변환합니다.

```js
export const countAtom = atom(0)
```

안으로:

```js
export const countAtom = atom(0)
countAtom.debugLabel = 'countAtom'
```

파일 이름 지정에 따라 기본 내보내기도 처리됩니다.

```js
// countAtom.ts
export default atom(0)
```

다음과 같이 변환됩니다.

```js
// countAtom.ts
const countAtom = atom(0)
countAtom.debugLabel = 'countAtom'
export default countAtom
```

### 사용법

불필요한 오버헤드를 피하기 위해 프로덕션 빌드에서는 이 플러그인을 비활성화하는 것이 좋습니다. 환경에 따라 Babel 구성에 조건부로 포함할 수 있습니다.

## jotai-babel/preset

Jotai에는 Jotai용으로 생성된 플러그인이 포함된 `babel preset`가 함께 제공됩니다.

### 사용법

`babel` 구성 파일 사용:

```json
{
  "presets": ["jotai-babel/preset"]
}
```

또한 사전 설정에 원자 이름을 제공할 수도 있습니다.

```json
{
  "presets": [["jotai-babel/preset", { "customAtomNames": ["customAtom"] }]]
}
```
