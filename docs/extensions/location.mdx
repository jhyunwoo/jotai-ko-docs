`window.location`를 처리하기 위해 원자를 생성하는 몇 가지 기능이 있습니다.

### 설치

이 기능을 사용하려면 `jotai-location`를 설치해야 합니다.

```
npm install jotai-location
```

## atomWithLocation

```js
atomWithLocation(options): PrimitiveAtom
```

`atomWithLocation`는 `window.location`에 연결되는 새로운 원자를 생성합니다.

일반적으로 `atomWithLocation`는 애플리케이션당 한 번만 인스턴스화해야 합니다. 한 인스턴스에 대한 변경 사항이 다른 인스턴스에 반영되지 않을 수 있기 때문입니다.
이 Atom은 `window.location` 개체와 동기화되도록 설계되었으므로 여러 인스턴스를 사용하면 예측할 수 없는 동작이 발생할 수 있습니다.

### 매개변수

**options** (선택 사항): atom의 동작을 맞춤 설정하는 옵션 객체

### 옵션

**preloaded** (선택 사항): 초기화 시 위치를 가져오지 않도록 하기 위한 미리 로드된 위치 값입니다.

**replace** (선택 사항): `pushState` 대신 `replaceState`를 사용함을 나타내는 부울입니다.

**getLocation** (선택 사항): 위치 값을 가져오는 사용자 정의 함수입니다.

**applyLocation** (선택사항): 위치 값을 설정하는 사용자 정의 함수입니다.

**subscribe** (선택사항): 위치 변경을 구독하는 사용자 정의 함수입니다.

### 예제

```jsx
import { useAtom } from 'jotai'
import { atomWithLocation } from 'jotai-location'

const locationAtom = atomWithLocation()

const App = () => {
  const [loc, setLoc] = useAtom(locationAtom)
  return (
    <ul>
      <li>
        <button
          style={{
            fontWeight: loc.pathname === '/' ? 'bold' : 'normal',
          }}
          onClick={() => setLoc((prev) => ({ ...prev, pathname: '/' }))}
        >
          Home
        </button>
      </li>
      <li>
        <button
          style={{
            fontWeight:
              loc.pathname === '/foo' && !loc.searchParams?.get('bar')
                ? 'bold'
                : 'normal',
          }}
          onClick={() =>
            setLoc((prev) => ({
              ...prev,
              pathname: '/foo',
              searchParams: new URLSearchParams(),
            }))
          }
        >
          Foo
        </button>
      </li>
      <li>
        <button
          style={{
            fontWeight:
              loc.pathname === '/foo' && loc.searchParams?.get('bar') === '1'
                ? 'bold'
                : 'normal',
          }}
          onClick={() =>
            setLoc((prev) => ({
              ...prev,
              pathname: '/foo',
              searchParams: new URLSearchParams([['bar', '1']]),
            }))
          }
        >
          Foo?bar=1
        </button>
      </li>
    </ul>
  )
}
```

## atomWithHash

```js
atomWithHash(key, initialValue, options): PrimitiveAtom
```

그러면 URL 해시와 연결된 새 원자가 생성됩니다.
해시는 URLSearchParams 형식이어야 합니다.
이는 양방향 바인딩입니다. 원자 값을 변경하면 해시가 변경되고
해시를 변경하면 원자 값이 변경됩니다.
이 기능은 DOM에서만 작동합니다.

### 매개변수

**key** (필수): localStorage, sessionStorage 또는 AsyncStorage와 상태를 동기화할 때 키로 사용하는 고유 문자열

**initialValue** (필수): 원자의 초기 값

**options** (선택 사항): atom의 동작을 맞춤 설정하는 옵션 객체

### 옵션

**serialize** (선택 사항): atom 값을 해시로 직렬화하는 사용자 정의 함수입니다. 기본값은 `JSON.stringify`입니다.

**deserialize** (선택 사항): 해시를 atom 값으로 역직렬화하는 사용자 정의 함수입니다. 기본값은 `JSON.parse`입니다.

**subscribe** (선택 사항): 사용자 정의 해시 변경 구독 함수

**setHash** (선택 사항): `replaceState` 또는 브라우저 쪽에서 해시가 업데이트되는 방식을 설명하는 사용자 정의 함수입니다. 기본적으로 `window.location.hash = searchParams`([jotai-location#4](https://github.com/jotaijs/jotai-location/pull/4))를 통해 새 항목을 history에 추가합니다.

### 예제

```jsx
import { useAtom } from 'jotai'
import { atomWithHash } from 'jotai-location'

const countAtom = atomWithHash('count', 1)

const Counter = () => {
  const [count, setCount] = useAtom(countAtom)
  return (
    <div>
      <div>count: {count}</div>
      <button onClick={() => setCount((c) => c + 1)}>+1</button>
    </div>
  )
}
```
