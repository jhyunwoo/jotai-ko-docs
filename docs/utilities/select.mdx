## selectAtom

⚠️ 이름과 달리 `selectAtom`은 탈출용 해치로 제공됩니다. 그것을 사용한다는 것은 100% 순수한 원자 모델을 만드는 것이 아니라는 것을 의미합니다. 파생된 원자를 사용하는 것을 선호하고 `equalityFn` 또는 `prevSlice`가 불가피한 경우에만 `selectAtom`를 사용하세요.

### 서명

```ts
function selectAtom<Value, Slice>(
  anAtom: Atom<Value>,
  selector: (v: Value, prevSlice?: Slice) => Slice,
  equalityFn: (a: Slice, b: Slice) => boolean = Object.is,
): Atom<Slice>
```

이 함수는 값이 원래 원자 값의 함수인 파생 원자를 생성합니다.
`selector.`에 의해 결정됨
선택기 기능은 원래 원자가 변경될 때마다 실행됩니다. 파생 원자를 업데이트합니다.
`equalityFn`가 파생된 값이 변경되었음을 보고하는 경우에만 해당됩니다.
기본적으로 `equalityFn`는 참조 동일성이지만 선호하는 완전 동일성을 제공할 수 있습니다.
필요한 경우 파생된 값을 안정화하는 기능을 수행합니다.

### 예제

```js
const defaultPerson = {
  name: {
    first: 'Jane',
    last: 'Doe',
  },
  birth: {
    year: 2000,
    month: 'Jan',
    day: 1,
    time: {
      hour: 1,
      minute: 1,
    },
  },
}

// 원래 원자.
const personAtom = atom(defaultPerson)

// person.name을 추적합니다. person.name 객체가 변경되면 업데이트됩니다.
// name.first와 name.last가 실제로 변경되지 않은 경우.
const nameAtom = selectAtom(personAtom, (person) => person.name)

// 사람.출생을 추적합니다. 연도, 월, 일, 시 또는 분이 변경되면 업데이트됩니다.
// deepEquals를 사용하면 출생 필드가 다음과 같은 경우 이 원자가 업데이트되지 않음을 의미합니다.
// 동일한 데이터를 포함하는 새 개체로 대체됩니다. 예를 들어, 사람을 다시 읽는 경우
// 데이터베이스에서.
const birthAtom = selectAtom(personAtom, (person) => person.birth, deepEquals)
```

### 안정적인 레퍼런스 보유

항상 그렇듯이 렌더링 주기에서 `useAtom`를 사용할 때 무한 루프를 방지하려면 `useAtom` 원자에 대한 안정적인 참조를 제공해야 합니다.
`selectAtom`의 경우 안정적이려면 기본 원자와 선택자가 **둘 다** 필요합니다.

```js
const [value] = useAtom(selectAtom(atom(0), (val) => val)) // 그러면 무한 루프가 발생하게 됩니다
```

이러한 제약 조건을 충족하기 위한 여러 옵션이 있습니다.

```js
const baseAtom = atom(0) // 안정적인
const baseSelector = (v) => v // 안정적인
const Component = () => {
  // 해결 방법 1: "useMemo"를 사용하여 결과 원자 전체를 메모합니다.
  const [value] = useAtom(useMemo(() => selectAtom(baseAtom, (v) => v), []))

  // 해결 방법 2: "useCallback"을 사용하여 인라인 콜백을 메모합니다.
  const [value] = useAtom(
    selectAtom(
      baseAtom,
      useCallback((v) => v, []),
    ),
  )

  // 해결 방법 3: 모든 제약 조건이 이미 충족되었습니다.
  const [value] = useAtom(selectAtom(baseAtom, baseSelector))
}
```
