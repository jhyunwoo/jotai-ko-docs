## atom

`atom` 함수는 atom config를 생성합니다.
값을 직접 담고 있는 것이 아니라 단지 정의만 나타내기 때문에 "atom config"라고 부릅니다.
문맥이 분명하다면 그냥 "atom"이라고 부르기도 합니다.

atom config는 불변 객체입니다. atom config 객체 자체는 값을 저장하지 않습니다.
atom 값은 store 안에 존재합니다.

primitive atom(config)을 만들려면 초기값만 전달하면 됩니다.

```js
import { atom } from 'jotai'

const priceAtom = atom(10)
const messageAtom = atom('hello')
const productAtom = atom({ id: 12, name: 'good stuff' })
```

파생 atom도 만들 수 있습니다. 패턴은 세 가지입니다.

- 읽기 전용 atom
- 쓰기 전용 atom
- 읽기-쓰기 atom

파생 atom을 만들 때는 읽기 함수와 선택적인 쓰기 함수를 전달합니다.

```js
const readOnlyAtom = atom((get) => get(priceAtom) * 2)
const writeOnlyAtom = atom(
  null, // 첫 번째 인수에는 `null`을 전달하는 것이 관례입니다.
  (get, set, update) => {
    // `update`는 이 atom을 갱신할 때 전달받는 단일 값입니다.
    set(priceAtom, get(priceAtom) - update.discount)
    // 또는 두 번째 인수로 함수를 전달할 수도 있습니다.
    // 이 함수는 atom의 현재 값을 첫 번째 인수로 받아 호출됩니다.
    set(priceAtom, (price) => price - update.discount)
  },
)
const readWriteAtom = atom(
  (get) => get(priceAtom) * 2,
  (get, set, newPrice) => {
    set(priceAtom, newPrice / 2)
    // 동시에 원하는 만큼 많은 atom을 설정할 수 있습니다.
  },
)
```

읽기 함수 안의 `get`은 atom 값을 읽는 데 사용됩니다.
반응형으로 동작하며 읽기 의존성이 추적됩니다.

쓰기 함수 안의 `get`도 atom 값을 읽는 데 사용되지만, 의존성은 추적되지 않습니다.
또한 Jotai v1 API에서는 아직 resolve되지 않은 비동기 값을 읽을 수 없습니다.

쓰기 함수 안의 `set`은 atom 값을 쓰는 데 사용됩니다.
대상 atom의 쓰기 함수를 호출합니다.

### 렌더 함수에서 atom을 생성할 때의 참고 사항

atom config는 어디서든 생성할 수 있지만 참조 동일성이 중요합니다.
동적으로 생성하는 것도 가능합니다.
렌더 함수 안에서 atom을 생성하려면 안정적인 참조를 얻기 위해 `useMemo` 또는 `useRef`가 필요합니다.
메모이제이션에 `useMemo`와 `useRef` 중 무엇을 써야 할지 확신이 없다면 `useMemo`를 사용하세요.
그렇지 않으면 `useAtom`과 함께 무한 루프가 발생할 수 있습니다.

```js
const Component = ({ value }) => {
  const valueAtom = useMemo(() => atom({ value }), [value])
  // ...
}
```

### 시그니처

```ts
// 기본 atom
function atom<Value>(initialValue: Value): PrimitiveAtom<Value>

// 읽기 전용 atom
function atom<Value>(read: (get: Getter) => Value): Atom<Value>

// 쓰기 가능한 파생 atom
function atom<Value, Args extends unknown[], Result>(
  read: (get: Getter) => Value,
  write: (get: Getter, set: Setter, ...args: Args) => Result,
): WritableAtom<Value, Args, Result>

// 쓰기 전용 파생 atom
function atom<Value, Args extends unknown[], Result>(
  read: Value,
  write: (get: Getter, set: Setter, ...args: Args) => Result,
): WritableAtom<Value, Args, Result>
```

- `initialValue`: 값이 변경되기 전까지 atom이 반환할 초기값입니다.
- `read`: atom을 읽을 때마다 평가되는 함수입니다. `read`의 시그니처는 `(get) => Value`이며, `get`은 atom config를 받아 Provider에 저장된 값을 반환하는 함수입니다. 의존성이 추적되므로, 어떤 atom에 대해 `get`이 한 번이라도 사용되면 그 atom 값이 바뀔 때마다 `read`가 다시 평가됩니다.
- `write`: 주로 atom 값을 변경하는 데 쓰이는 함수입니다. `useAtom`이 반환하는 튜플의 두 번째 값, 즉 `useAtom()[1]`를 호출할 때마다 실행됩니다. primitive atom에서는 이 함수의 기본 구현이 해당 atom의 값을 변경합니다. `write`의 시그니처는 `(get, set, ...args) => Result`입니다. `get`은 위에서 설명한 것과 비슷하지만 의존성을 추적하지 않습니다. `set`은 atom config와 새 값을 받아 Provider 안의 atom 값을 갱신하는 함수입니다. `...args`는 `useAtom()[1]`를 호출할 때 전달하는 인수들이고, `Result`는 `write` 함수의 반환값입니다.

```js
const primitiveAtom = atom(initialValue)
const derivedAtomWithRead = atom(read)
const derivedAtomWithReadWrite = atom(read, write)
const derivedAtomWithWriteOnly = atom(null, write)
```

atom에는 두 종류가 있습니다. writable atom과 read-only atom입니다.
primitive atom은 항상 writable입니다.
파생 atom은 `write`가 지정된 경우에 writable입니다.
primitive atom의 `write`는 `React.useState`의 `setState`와 같습니다.

### `debugLabel` 속성

생성된 atom config에는 선택적 속성 `debugLabel`을 지정할 수 있습니다.
debug label은 디버깅 시 atom을 표시하는 데 사용됩니다.
자세한 내용은 [Debugging guide](../guides/debugging.mdx)를 참고하세요.

참고: debug label은 반드시 고유할 필요는 없지만, 일반적으로 구분 가능하게 만드는 것이 좋습니다.

### `onMount` 속성

생성된 atom config에는 선택적 속성 `onMount`를 지정할 수 있습니다.
`onMount`는 `setAtom` 함수를 인수로 받고, 선택적으로 `onUnmount` 함수를 반환하는 함수입니다.

`onMount`는 atom이 provider에서 처음 구독될 때 호출되고,
`onUnmount`는 더 이상 구독되지 않을 때 호출됩니다.
경우에 따라([React strict mode](https://react.dev/reference/react/StrictMode) 등) atom이 언마운트된 직후 곧바로 다시 마운트될 수도 있습니다.

```js
const anAtom = atom(1)
anAtom.onMount = (setAtom) => {
  console.log('atom is mounted in provider')
  setAtom((c) => c + 1) // 마운트 시 카운트 증가
  return () => { ... } // 선택적인 onUnmount 함수를 반환
}

const Component = () => {
  // 다음 경우에는 컴포넌트가 마운트될 때 `onMount`가 호출됩니다.
  useAtom(anAtom)
  useAtomValue(anAtom)

  // 하지만 다음 경우에는 atom이 구독되지 않으므로
  // `onMount`가 호출되지 않습니다.
  useSetAtom(anAtom)
  useAtomCallback(
    useCallback((get) => get(anAtom), []),
  )
  // ...
}
```

`setAtom` 함수를 호출하면 해당 atom의 `write`가 실행됩니다.
`write`를 커스터마이즈하면 이 동작을 바꿀 수 있습니다.

```js
const countAtom = atom(1)
const derivedAtom = atom(
  (get) => get(countAtom),
  (get, set, action) => {
    if (action.type === 'init') {
      set(countAtom, 10)
    } else if (action.type === 'inc') {
      set(countAtom, (c) => c + 1)
    }
  },
)
derivedAtom.onMount = (setAtom) => {
  setAtom({ type: 'init' })
}
```

### 고급 API

Jotai v2부터 `read` 함수는 두 번째 인수 `options`를 받습니다.

#### `options.signal`

[AbortController](https://developer.mozilla.org/en-US/docs/Web/API/AbortController)를 사용해 비동기 함수를 중단할 수 있게 해줍니다.
새 계산(`read` 함수 호출)이 시작되기 전에 abort가 트리거됩니다.

사용 방법은 다음과 같습니다.

```ts
const readOnlyDerivedAtom = atom(async (get, { signal }) => {
  // signal을 사용해 함수를 중단합니다.
})

const writableDerivedAtom = atom(
  async (get, { signal }) => {
    // signal을 사용해 함수를 중단합니다.
  },
  (get, set, arg) => {
    // ...
  },
)
```

`signal` 값은 [AbortSignal](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal)입니다.
`signal.aborted` 불리언 값을 확인하거나, `addEventListener`와 함께 `abort` 이벤트를 사용할 수 있습니다.

`fetch`를 사용하는 경우에는 `signal`만 그대로 넘기면 됩니다.

아래 예제에서 `fetch` 사용법을 확인해 보세요.

#### `options.setSelf`

자기 자신 atom의 쓰기 함수를 호출하기 위한 특별한 함수입니다.

⚠️ 이 기능은 주로 내부 구현과 서드파티 라이브러리 작성자를 위해 제공됩니다. 동작을 제대로 이해하려면 소스 코드를 주의 깊게 읽으세요. 호환성이 깨지는 변경이든 아니든 릴리스 노트를 확인하는 것이 좋습니다.

## Stackblitz

<Stackblitz id="vitejs-vite-ccqxix" file="src%2FApp.tsx" />

```tsx
import { Suspense } from 'react'
import { atom, useAtom } from 'jotai'

const userIdAtom = atom(1)
const userAtom = atom(async (get, { signal }) => {
  const userId = get(userIdAtom)
  const response = await fetch(
    `https://jsonplaceholder.typicode.com/users/${userId}?_delay=2000`,
    { signal },
  )
  return response.json()
})

const Controls = () => {
  const [userId, setUserId] = useAtom(userIdAtom)
  return (
    <div>
      User Id: {userId}
      <button onClick={() => setUserId((c) => c - 1)}>Prev</button>
      <button onClick={() => setUserId((c) => c + 1)}>Next</button>
    </div>
  )
}

const UserName = () => {
  const [user] = useAtom(userAtom)
  return <div>User name: {user.name}</div>
}

const App = () => (
  <>
    <Controls />
    <Suspense fallback="Loading...">
      <UserName />
    </Suspense>
  </>
)

export default App
```
