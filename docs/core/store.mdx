## createStore

이 함수는 새로운 빈 store를 생성합니다.
store는 `Provider`에 전달해서 사용할 수 있습니다.

store에는 세 가지 메서드가 있습니다. `get`은 atom 값을 읽고,
`set`은 atom 값을 설정하며, `sub`는 atom 변경 사항을 구독합니다.

```jsx
const myStore = createStore()

const countAtom = atom(0)
myStore.set(countAtom, 1)
const unsub = myStore.sub(countAtom, () => {
  console.log('countAtom value is changed to', myStore.get(countAtom))
})
// unsub()로 구독 해제

const Root = () => (
  <Provider store={myStore}>
    <App />
  </Provider>
)
```

## getDefaultStore

이 함수는 Provider-less 모드에서 사용되는 기본 store를 반환합니다.

```js
const defaultStore = getDefaultStore()
```
