Jotai v2 문서에 오신 것을 환영합니다! Jotai의 atomic 접근 방식은 단순한 `useState` 대체 수준부터 복잡한 요구사항을 가진 엔터프라이즈 애플리케이션까지 확장 가능한 React 전역 상태 관리를 제공합니다.

## 기능

- 최소한의 코어 API (2kb)
- 많은 유틸리티 및 확장
- TypeScript 지향
- Next.js, Waku, Remix 및 React Native와 함께 작동합니다.

## 코어

Jotai는 매우 작은 API를 제공하며, 메인 `jotai` 번들에서 노출되는 export는 몇 개뿐입니다. 이들은 아래 네 가지 범주로 나뉩니다.

## 유틸리티

Jotai에는 다양한 추가 유틸리티 기능이 포함된 `jotai/utils` 번들도 포함되어 있습니다. 한 가지 예는 `atomWithStorage`이며, 여기에는 localStorage 지속성과 브라우저 간 탭 동기화가 포함됩니다.
